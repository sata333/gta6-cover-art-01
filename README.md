Poster Cover Studio is a static web app that turns a photo and a caption into GTA-poster-style cover art: a multi-panel collage with white gutters, a Vice City sunset or neon colour grade, and big bold caption lettering. Arrange per-panel crops, pick from five layouts and three grades, then export a PNG at 1080×1080, 1080×1350 or 1920×1080 — all offline, no build step.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 in a desktop browser.
